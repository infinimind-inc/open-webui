# How to run this repo
 
1. Locally, we simply execute `run.sh` to deploy.
2. Once the container is running, open a browser and go to http://localhost:8080
3. Log into the system using the following credentials:

```
username: e@g.com
password: holahola
```

4. Create a new chat with the model called `nvidia/nemotron-3-nano-omni`, which should be available in the models dropdown list.
5. Test that the model is working by simply sending a "Hi!" message and waiting for the reply.
6. Try attaching a path to a remote file (a video, located in `file:///ephemeral/space_woaudio.mp4`) and ask "Summarize this video".

If all of the above steps were successful, you're done.
